# Active focus

This clone is **TEB Ask** only: sign-in then a full-page chatbot. Quote composer, manage grid, and the app rail are not part of the UI.

Ask is a **two-step journey** (`src/lib/chat/journey.ts`, `ChatPanel`): first load asks “What do you want to know today?” and lists **permitted apps** from `GetMenuDetail`. If the live menu is empty, Ask still shows Sales / Service / Finance / Workforce / Reports so the picker is never stuck. Picking an app shows starter questions plus a search box. **All apps** returns to the picker without wiping the thread. History is stored on this browser in `localStorage` (`teb.ask.journey.{UserId}`) — not a TEB database. **Clear chat** wipes the thread and charts. Last turns are sent to `/api/ask/analyze`.

Ask also understands **Management Dashboard** (`TEBDashboard`, `/sales/dashboard`). That stack POSTs an unwrapped `FilterDetail` to MICRO `gateway/reporting/{Method}` — not Manage `FilterValues`. Toolbar: DATEFILTER, OWNERFILTER, assignee, workflow, location, items, FilterId. No entity → `GetTeamBasedRecordsCount` (team snapshot). Entity snapshot → `GetModuleWiseOverviewDashboard` (`QUOTESNAPSHOT`, `LEADSNAPSHOT`, …) then `GetTeamBased*Details`. Phrases: `Team snapshot this month`, `Quote snapshot owned by me last 7 days`, `What filters can I use on the dashboard?`.

Ask report and error copy is subscriber-facing: no API hosts, module codes, or `Source: DYNAMIC …` lines. Failures map through `userFacingAskError`.

Service Ticket / Work Order filters: `GetFilterControls` uses list codes `TEBTicket` / `TEBWorkorder` + `MANAGE`. ExtraApi lookups send live FIXED params (`TICPRI`, `TICT`). Wrapped list FilterValues sit inside `Data` JSON because `FilterModule` 400s. Stage/status phrases (`Follow Up`, `Assign to Engineer`) map to the live workflow tree.

Ask uses live Created Filter modes (`ANY` / `WITHIN` last N months-years / `BETWEEN` last N days and calendar phrases / `FINANCIALPERIOD`) on TabCode `DATE`, charts the filtered set, and asks `/api/ask/analyze` (OpenAI or Anthropic) for commentary. **Last N days** is a local calendar `BETWEEN` from today-(N-1) through **today** (not UTC-sliced ISO, and not WITHIN that can drop today). Analysis totals use `QuoteCurrentValue` / `QuoteNetValue` (skipping 0 placeholders) and bold counts/amounts. Line charts use month labels like `Jul 26` / `Sept 26` (not `07`) with the count on each point. Stored timestamps (`2026-09-11T09:38:23.107Z`) display as local dates (`11 Sep 2026, 3:08 pm`). Opportunity lists that 400 on unwrapped `TEBSale` FilterValues fall back to SalesManagement `MANAGE` (FilterModule) or an unfiltered list with the date applied locally. Error answers include clickable follow-up chips. **Leads created by {user}** uses the live Lead OWNER lookup (`GetSubscriberActiveUsers`) and the `CreatedBy` / `OwnerName` columns — not an unfiltered lead list.

Ask entities: Company (`TEBBusiness` / `GetCustomerDetail` `COMPANY`), Contact (`TEBPeople` / `CONTACT`), Quote, Lead, Opportunity, Order, Invoice, Receipt, Service Ticket, Work Order, Action (`TEBAction` / `GetTeamAndMemberBasedActionDetails`), Workforce. Company/contact cards show `PhoneDetail` / `EmailDetail` as `tel:` and `mailto:` links. Search uses MICRO `getcustomerdetails`; profile uses Dynamic `GETCOMPANYDETAIL` / `GETCONTACTDETAIL`. A contact can open the parent company via `CompanyId`. Manage filters try `COMPANYFILTER` / `CONTACTFILTER` and otherwise synthesize owner, location, industry, sector, source, relationship, contact type, date, and workflow.

Quote **view** in Ask is read-only (not the live composer). Phrases: `View quote Q-1024`, `Quote profile for …`, `Open quote …`. It loads `GETQUOTEDETAIL`, items via EstimationManagement `VIEWCONSUMEDITEM` (`ItemDetail` + `TotalSummary`), templates via `getsubscribertemplatedropdown`, notes via `GetSubscriberNotes`, actions via `GETQUOTEACTIVITY`. Each quote template is a PDF from TEMPLATE `AcDownloadPdf` `SAVETEMPLATE` (`Code: TEBQuote`, `Data: { EntityId, Module: TEBQuote, TemplateId }`); Ask previews the PDF in chat. Items + totals render as a receipt card (name left, amount right, Total Amount emphasized). `VIEWCONSUMEDITEM` `ItemDetail` often ends with an empty composer placeholder (no product name, amount 0, fallback label “Item”) — Ask drops that row. **Open in TEB** is `https://live.teb.cloud/sales/quote/view/{id}` (`NEXT_PUBLIC_TEB_LIVE_APP`). This app must not navigate to `/sales/quote/view/:id`.

**Find my team** matches live `/workforce/team`: Workforce user dropdown → `GetSignedInUsersLastLocation` → OSM pins. A named user uses `GetUserLastLocation`. Last-location `Address` is often null or `0`; Ask fills `CurrentAddress` / `StartAddress` from `CurrentDateUserTrackingInfo` (and route `GetUserTrackingListView`) instead of showing `0` or raw lat/long. Pin labels use directory names, never 24-char UserIds. **Show route for me / Route of {username}** matches `/workforce/route`: `GetUserTrackingMapView` (`TrackLogRequest` UserId + CurrentDate) and plots start/end pins + PolylineList. Field logins often get an empty TEBWorkforce dropdown; Ask falls back to team-member APIs and matches people on `UserId` / username.

**How many people started {date}** is punch-in / present, not DateOfJoining. Counts come from Management Dashboard `GetOverviewWorkforceSnapshot` (`STARTDAY` / `ENDDAY` / `FORCEDENDDAY` / `NOTSTARTDAY`). Names come from Workforce Day Manage `GetTrackingSummary` (`StartEventTime` / `EndEventTime` / `UserIds` from `GetUserDropdown?Module=TEBWorkforce` `Id`). Default date is today. Joining-date questions stay on `joined on` / `joining date`.

This login’s snapshot payload is team rows with nested `AppWiseCount` / `TotalCount` (not `Count`), so Ask showed **0**. Calendar dates used `DatePeriod.Period: null`, which 400s on reporting. Fix: flatten app counts, send `Period: 0`, and fall back to `GetTeamBased*Details` / unfiltered MANAGE when FilterValues are rejected (`Filter form not created`).

Money in Ask uses the same mapped currency as the Quote APIs (INR `Rs` → `₹`). Do not default GenAI amounts to `$`.

After login the user always lands on `/`. `/sales/...` redirects to `/`.

Publish as Next.js on HTTPS (not a static SPA zip). Mobile users install it as a **PWA**: Android “Install app”, iPhone Share → Add to Home Screen. Manifest + service worker live in `src/app/manifest.ts` and `public/sw.js`.
